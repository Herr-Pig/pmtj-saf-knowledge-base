## 对象、膜堆与热处理

这是双MgO记录层框架，不含Co/Pt参考桥或Ru-SAF。Sample C为W5/MgO2/CoFeB1.5/W(tW)/CoFeB1.2/MgO2/W5（nm）；Co20Fe60B20靶，W扫0.10–2.70nm。退火250–425°C、1h，面外30kOe；VSM测面内/面外回线（p.2、Methods p.6）。A/B为不同单CoFeB界面次序，不是仅删去W的完整pMTJ。

## 作者解释与未证明事项

作者提出B吸收、界面PMA及互扩散抑制等解释，并在p.5及p.6明确保留机理未澄清；没有本篇Jc实测。原文p.5将0.25nm称为高于400°C保持PMA的最小厚度，但p.4同时称0.25nm从400°C起劣化，不能自行消除差异。p.3文字把TEM指到Fig.4(d)，可见对应图在Fig.1(d)；SI S2(b)图注又回指S1(a)，均保留为原文定位差异。公式Keff=Ms·Hk/2和J=Hex·Ms·t在正文为无编号式，不擅自补公式号或SI单位因子。
