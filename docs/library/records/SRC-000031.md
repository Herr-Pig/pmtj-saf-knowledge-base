## 研究对象与条件

Ni81Fe19(1)/Ir25Mn75(15)/Co32Fe48B20(5)/MgO(2)/Co32Fe48B20(4)/Cap，5µm结；Cap比较Pt及Ta/W再加Pt。室温读出时扫**面内磁场**，退火40min并施加100mT以建立交换偏置（§2，PDF pp.2–3）。不是Co/Pt-Ru SAF或垂直参考桥的直接对照。

## 原文差异及附件

正文p.5将Ta/W封盖写为5nm，Fig.3/4图注写4nm。本库保留此差异，不替作者选择数值。XRD组另有明确独立层序。官方SI入口包含S1（W扩散）与S2（B与结晶）；请求返回HTML而非ZIP，标为**未取得/未核读**。机构PDF用于本轮阅读，正文图页存在重复文字提取层，图号按可见PDF页与图注核对，不将隐藏重复文字计为重复实验。
