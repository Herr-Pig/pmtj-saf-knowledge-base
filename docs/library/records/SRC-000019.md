## 对象与膜堆
单/双pSAF GMR传感器，Ru间隔4Å；双pSAF含3个FM块；上方Cu20Å和面内自由层。Co/Pt重复数X/Y、自由层类型Sa–Sd及全层序见作者稿pp.1–2 Fig.1，不能替换成MgO PMTJ。
