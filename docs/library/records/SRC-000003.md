## 研究对象与实际膜堆
研究FeCoB/(Ta)/Ru/FeCoB SAF2及其由存储层转为参考层的设计。初始结构M1/Ru/M2/MgO/Mb/(Ta)/Ru/Mt/MgO；M1、M2为含Co/Pt的硬SAF1，M2经Ta0.3连FeCoB（p.2）。Fig.1的SAF2为FeCoB1.4/Ru0.6/FeCoB1.1或Ta0.2/Ru0.5间隔层（nm）。未逐层给出的SAF1厚度不补写。
