# PMTJ-SAF 公开研究资料库：范围与证据协议

批准执行日期：2026-10-27。阶段目标：公开资料发现、原文阅读、证据定位和跨文献比较。

## 工作边界

- 六个专题见 [阅读入口](index.md)。覆盖原始研究、SI、学位论文、会议论文/报告、技术报告、讲座和实验视频。
- 第一阶段未开发网页；第二阶段按用户授权建设MkDocs Material本地网站，暂不部署公网。不读取、处理、拟合、上传或修改用户实验数据，不修改既有模型任务规格。构建仅读取公开文件清单，排除inputs和历史实验材料。
- 现有研究笔记和历史对话仅作为历史背景及检索线索。旧版“已核实”标签不自动传递到新资料库。
- 本阶段为可扩展的范围检索与证据整理，不宣称穷尽全部文献或完成正式系统综述。

## 收录与优先级

原始实验优先，重点保留实际膜堆、厚度系列、MOKE/M-H、minor loop、PMA或耦合表征。理论研究按模型问题独立收录；综述用于导航，不能替代原始研究。相邻体系可以作为机制参照，但必须写明材料、结构和测量差异。

中英文均纳入，不设起始年份；每次检索记录实际日期和所用来源。无法取得正文者仍可登记候选，但不得从摘要补写图号、层序或详细结论。

## 独立状态字段

1. 身份：官方元数据已核对 / 部分核对 / 无法唯一定位。
2. 正文：本地已验证 / 官方在线全文已读 / 仅摘要 / 未取得。
3. SI：本地已验证 / 官方在线已读 / 链接已找到未读 / 未找到 / 未确认 / 不适用（须有依据）。
4. 阅读：已完成关键证据核对 / 部分阅读 / 未读。
5. 单条论断类型：作者实验结果 / 作者模型结果 / 作者解释或假设 / 二手转述 / 本库推断。

“元数据已核对”不等于“科学结论已验证”；“未找到SI”不等于“论文无SI”。缺项分别写“原文未说明”“尚未取得”“未核实”“不适用”，不使用猜测值。

第二阶段增加来源级显示字段：**核心证据/核心证据候选、辅助资料、背景资料**；E1为关键原始证据已定位，E2为方法或课程选读，E3为身份/摘要/部分阅读。它们描述资料角色与阅读状态，不为真实性打分，也不意味着独立复现。单条结论仍须区分实验、模型、解释与本库推断。

P1为会影响核心结论或可比性的未解决项；P2为辅助补充或复现扩展；P3为背景扩展。P0紧急身份核验（本轮013）已关闭，不因此关闭其科学解释差异。具体任务见[缺口清单](gaps/missing-materials.md)。

## 原文与文件协议

- 使用稳定编号 SRC-000001；一份资料一个记录，可进入多个专题。
- DOI大小写规范化去重；无DOI时人工核对标题、作者、年份、机构永久标识。预印本、期刊版、报告和学位论文建立版本关系，不盲目合并。
- 优先官方出版页、作者/高校合法仓储、官方会议或机构发布页。仅保存实际成功获取的文件；PDF验证签名、页数及标题，记录来源URL、日期与SHA-256。
- 学位论文记录学校、学位和章节/印刷页；视频记录讲者、活动、时间戳和字幕来源。未观看的片段不写成已核对证据。
- 原文页码与PDF页序分别记录；HTML使用小节、图号、公式号及独有段落开头定位。页面未编号时如实说明。
- 只保存支持核验所需的短引文与原创概述；不将长篇全文翻译或图像重发布作为默认输出。

## 实际膜堆与证据提取

层序按原文保留，从衬底/种子层到覆盖层注明方向，厚度与重复次数须带单位。一个来源内不同样品使用来源自己的编号；不能以“典型结构”补齐其余样品。

每条关键论断绑定图/公式/表/页或时间戳，并写明作者直接观察、模型推导、解释和本库推断的区别。对照表记录至少：材料相邻关系、W/Ru位置、厚度、PMA参数、退火、测量方向、扫场分支和场量定义。若原文未提供，则标缺，不推断。

不同文献的J符号、H/B单位、能量密度及因子约定先分别记录，再讨论可比性。本阶段不自动修正旧笔记公式，也不从论文图中自行生成实验数据点。

## 阶段验收

- 六个专题均有实质阅读、至少一组跨来源比较和明确证据边界。
- 索引、catalog.json、记录编号与附件一致；内部链接有效。
- 核心结论有原文锚点；未取正文/SI和无法定位的资料进入缺口清单。
- 各阶段报告新增/更新文件、已核实资料、未解决项和下一步。
